## OWED_API

### Overview

Owed is a lightweight, user-friendly application designed to simplify shared expense tracking and bill splitting for
friends, roommates, and groups. Whether for a weekend trip, a group dinner, or daily shared living costs, the app
removes the complexity of financial math by leveraging AI-powered receipt scanning and automated debt calculation.
